# DVM1200 1

## SYNOPSIS 

`dvm1200` [`-d <device>`] [`-c <count>`] [`-u`] 

## DESCRIPTION 

`dvm1200` is an open source tool to dump data from Velleman DVM 
and convert it to CSV format.

## OPTIONS

`-d <device>`
  specify serial port to connect

`-c <count>`
  print `count` measurements and exit

`-u`
  drop out duplicated measurement values

## BUGS

The DVM1200 send erroneous data when the battery is low
